# ByteFlow 项目总结

## 项目概述

**ByteFlow** 是一个完整的 macOS 网络流量监控应用，具有多精度历史图表功能。本项目从零开始实现，包含完整的后端采集、数据存储、API 服务和前端可视化。

## 完成情况

✅ **所有需求已完成**

### 核心功能 ✅
- [x] 监控所有应用/进程的网络流量
- [x] 实时显示下载/上传速率和总流量

## 核心设计决策

### 1. 为什么选择 nettop？
- ✅ macOS 原生工具，无需额外安装
- ✅ 无需系统扩展或 App Store 签名
- ✅ 可靠的进程级流量统计
- ❌ 限制：需要终端权限

### 2. 为什么使用三层数据存储？
- ✅ 平衡精度和存储空间
- ✅ 支持多时间范围查询
- ✅ 自动数据汇总减少存储
- 📊 数据库大小通常 < 100MB

### 3. 为什么选择 FastAPI？
- ✅ 现代化的 Python Web 框架
- ✅ 自动生成 API 文档
- ✅ 类型提示和验证
- ✅ 高性能异步支持

### 4. 为什么使用原生 JavaScript？
- ✅ 无需构建工具
- ✅ 零配置直接运行
- ✅ 轻量级单文件
- ✅ 易于理解和修改

## 数据流设计

```
macOS 系统网络活动
    ↓
nettop 命令 (每秒采样)
    ↓
collector.py 解析和计算
    ↓
SQLite 数据库
├── traffic_raw (秒级, 24h)
├── traffic_minute (分钟级, 7d)  ← 每分钟汇总
└── traffic_hour (小时级, 30d)   ← 每小时汇总
    ↓
FastAPI REST API
├── GET /api/overview
├── GET /api/history/{app}
└── GET /api/stats
    ↓
Web 浏览器
├── 概览表格
└── Chart.js 历史图表
```

## 已知限制

### 系统限制
- ❌ 仅支持 macOS（Linux/Windows 需要不同的采集方法）
- ❌ 需要 nettop 权限（首次可能需要授权）
- ⚠️ nettop 输出格式可能因系统版本而异

### 功能限制
- ⚠️ 不记录具体的网络连接详情
- ⚠️ 不支持按域名/IP 统计
- ⚠️ 不支持实时报警通知

### 性能限制
- ⚠️ 1秒采样间隔（可配置但不建议更频繁）
- ⚠️ 大量应用时表格可能较长
